### `03 // Mini Shell`

**C · Linux/POSIX · Flex/Bison · Process Management**

Implemented a Unix-like shell with AST-based parsing, built-ins, pipelines, argument expansion, I/O redirection, and sequential, conditional, and parallel execution using primitives such as `fork`, `execvp`, `waitpid`, `pipe`, and `dup2`.

[`>> view_repository`](https://github.com/andreiradu2102/Mini-shell)

### `04 // Time-Travel Postcards`

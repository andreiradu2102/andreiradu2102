## `> ml.profile --primary`

```text
DOMAIN        : Machine Learning Engineering
SPECIALTIES   : Multimodal ML · Computer Vision · NLP

ML WORKFLOW   : Training · Evaluation · Inference · API Integration · Deployment
RESEARCH      : Text · Video · Multimodal architectures
BEST RESULT   : 0.880 macro-F1
PUBLIC MODELS : 10 trained models
```

My bachelor's research focused on **misinformation detection in social-media videos** across text, video, and multimodal architectures.

I worked with:

- BERT-family architectures
- TimeSformer
- VideoMAE
- ViViT
- DistilBERT + VideoMAE
- CLIP
- SigLIP

The project included **LoRA fine-tuning, stratified cross-validation, frame caching, automated preprocessing and evaluation, zero-shot experiments, and live FastAPI inference**.

It won **1st Prize in the Distributed Systems section of UPB's Student Scientific Communications Session (SCSS)** and advanced to the competition's final stage.
